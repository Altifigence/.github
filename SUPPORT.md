# Support

- SDK usage: [developer guide](https://docs.altifigence.com/developers/plugin-sdk/),
  [Korean guide](https://docs.altifigence.com/ko-kr/developers/plugin-sdk/), then
  [SDK issues](https://github.com/Altifigence/dds-plugin-sdk/issues).
- Tool integrations: read the relevant repository and
  [DDS plugin guide](https://docs.altifigence.com/products/digital-design-studio/plugins/).
- Public profile or documentation navigation: use this repository's issues.
- Vulnerabilities: follow [private security reporting](SECURITY.md).

Include the exact package/product version, operating system, Node/Rust version
when relevant, expected behavior and a minimal reproducible example. SDK version,
tool version and DDS product version are different; report all applicable versions.
Remove tokens, personal data, private project files and restricted third-party
materials before sharing logs. Public repositories do not provide account access
or authorize distribution of proprietary product code.
